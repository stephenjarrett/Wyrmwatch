# Wyrmwatch 0.2.3

This release brings the saved-server workspace, smaller shared-runtime packages, safer world import and restore recovery, and clearer operation guidance to the public downloads.

- Create a server or import one reviewed world `.sav` into a standard managed installation. Import preserves the source and rechecks its fingerprint; configuration, character files and passwords are not copied. Previously connected profiles remain compatible.
- Recover the observed fresh SteamCMD exit-7 metadata failure with one bounded retry. Resume a prepared installation only when this workspace's receipt and complete file inventory still match.
- Protect save locations across connected and disconnected profiles. Interrupted restores retain a durable journal, block Start/writes and require explicit verified reconciliation. Recover missing/empty Saved folders and distinguish configuration-only from full world restores.
- Preserve owned Windows launcher children and Linux launcher/session handoffs while keeping shutdown graceful. Unowned and inaccessible processes remain protected.
- Show truthful operation phases, elapsed time, persistent errors, prerequisite explanations and destination links. Improve structured setup reviews, retry state, centered inputs, dark/light layouts, keyboard labels and bundled-font portability.
- Share one bundled .NET runtime between desktop and manager, retain matching source/notices and omit debugging symbols. Remove remote control and automatic app-release checks; manual update checks remain available.
- Isolate process-wide Desktop test settings between cases. The formerly intermittent demo-state failure has a deterministic demo-then-normal regression.

Automatic maintenance and background operation remain off by default. Opening the app does not install or start a game server. Disconnect preserves existing installation/save/backup files. No existing profile or world is automatically migrated.

## Downloads

- **Windows x64:** `Wyrmwatch-0.2.3-win-x64-setup.exe`, a per-user installer. It is currently unsigned.
- **Ubuntu/Debian x64:** `Wyrmwatch-0.2.3-linux-amd64.deb`.
- **Portable:** `Wyrmwatch-win-x64.zip` and `Wyrmwatch-linux-x64.tar.gz`.

Packages include the .NET runtime, matching source, AGPL license/notices and SHA-256 files. The prepared draft records its exact source commit and successful master run; public publication requires the matching approved `v0.2.3` tag and successful release checks on both platforms.

## Verification and limits

Automated coverage uses disposable servers and structural world fixtures. Native Linux desktop flows and native Windows screenshot layouts were checked separately. These checks do not certify real Dragonwilds world/game compatibility, physical power-loss behavior, every DPI setting or native screen-reader behavior. Structural SAVE/SPUD validation does not prove a world will load in game. Linux remains a preview until verified with a real Linux game installation. Keep an independent world backup and follow the [installation guide](https://github.com/stephenjarrett/Wyrmwatch/blob/v0.2.3/docs/installing.md).
