# Wyrmwatch 0.2.7

- Add **Download and update**: verify the package and restart the desktop automatically with its existing workspace. Running game servers stay running. If the manager is busy or restart fails, retry the retained package without downloading again. Installed services retain their explicit handoff flow.
- Retain each server's configured admin password if it is absent from the INI after a launch, and reapply it only before a verified stopped-server launch. Explicit configuration edits take precedence. Existing passwords already removed before this fix must be entered and saved once.
- Give Activity sections more space, enlarge scrollbars and keep console scrollbars visible. Follow log defaults on, remembers its preference, and follows the bounded latest 300 lines / 64 KB.
- Update existing Windows desktop shortcuts after an app update. Preserve the previous shortcut and workspace arguments.
- Show failed-operation messages accurately and link missing start settings directly to Server settings.

Saved admin passwords are protected for the current Windows user with DPAPI. Linux uses owner-only files (0600, including atomic temporary files and retained copies); these are not encrypted. Keep the manager workspace private. Game configuration and configuration backups can still contain plaintext passwords, as required by the game.

Includes Windows and Linux packages, source, AGPL-3.0-only notices and SHA-256 checksums. Tests use disposable servers and worlds. Linux remains a preview; actual Dragonwilds hosting and physical network paths require deployment validation.
