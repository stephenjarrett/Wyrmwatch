# Wyrmwatch 0.2.5

- Reduce portable and installer payloads by pruning unused assemblies while preserving reflection-dependent UI/JSON behavior and one shared bundled .NET runtime. Packages still include matching source, notices and SHA-256 files. No separately installed .NET is required.
- Keep the selected backup when the list refreshes, so verification and restore act on the intended archive.
- Automate patch versions and immutable release tags after successful current-master checks. Explicit read-only check dispatches avoid GitHub's suppressed bot push/tag events. Interrupted own setup can resume; failed checks, altered assets, unknown candidates and publication holds stop release writes.

Previous save ownership, restore recovery, managed world import, process ownership and UI safeguards remain in place. Opening the app does not install or start a game server. Maintenance remains opt-in. Existing profiles and saves are not migrated.

Windows x64 installer: `Wyrmwatch-0.2.5-win-x64-setup.exe` (unsigned). Ubuntu/Debian x64: `Wyrmwatch-0.2.5-linux-amd64.deb`. Portable downloads: `Wyrmwatch-win-x64.zip` and `Wyrmwatch-linux-x64.tar.gz`.

Automated tests use disposable process/world fixtures. They do not certify real Dragonwilds world compatibility, physical power-loss behavior, every DPI setting or native screen-reader behavior. Linux remains a preview. Keep an independent world backup. Wyrmwatch is unofficial, not affiliated with Jagex, and licensed AGPL-3.0-only.
