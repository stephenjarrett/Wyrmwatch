# Wyrmwatch 0.2.0

A desktop manager for RuneScape: Dragonwilds dedicated servers, with Windows and Linux interfaces, reviewed imports, verified backups, and optional background maintenance.

## Downloads

- **Windows x64:** `Wyrmwatch-0.2.0-win-x64-setup.exe` — installs for the current user and adds a Start menu shortcut.
- **Ubuntu/Debian x64:** `Wyrmwatch-0.2.0-linux-amd64.deb` — install with `sudo apt install ./Wyrmwatch-0.2.0-linux-amd64.deb`.
- **Portable:** `Wyrmwatch-win-x64.zip` and `Wyrmwatch-linux-x64.tar.gz`.

All packages include the .NET runtime, matching source, and license notices. SHA-256 files accompany the downloads. The Windows installer is unsigned. See [installation instructions](https://github.com/stephenjarrett/Wyrmwatch/blob/v0.2.0/docs/installing.md).

## Included

- A list of saved servers with one running at a time, external save-folder imports, and overlap safeguards.
- Start, graceful stop, resource display, activity history, and game configuration.
- Scheduled backups, integrity verification, and staged restore with retained recovery folders.
- Automatic game updates that defer while players are present or activity is unknown.
- Opt-in background operation, Windows/Linux service support, and an HTTPS dashboard with scoped, revocable access.
- Verified manager-update downloads, retained previous versions, themes, and community language packs.

Installation and first launch do not adopt or start a game server. Services, remote access, and automatic maintenance remain opt-in. Installer removal preserves user preferences, game files, saves, and backups.

## Verification and limits

The focused suite includes 81 core/agent tests and four headless UI tests on Windows and Ubuntu. Live fixture checks cover imports, process ownership, backup/restore, shared-port switching, remote permissions, and native Windows/Linux desktop flows. Ubuntu 24.04 package installation, busy-manager refusal, removal preservation, and systemd startup after restarting an isolated WSL2 distribution were exercised. Windows installer and low-privilege service lifecycle checks passed on disposable GitHub runners.

After publication, the installers' checksums and Windows updater download/extraction were verified against the public release. The Linux native update flow opened the published version while preserving a running fixture server, settings, and saves; reopening the retained previous app also passed.

This is an early release. Tests use disposable fake servers and preserve existing game installations. They do not certify actual Dragonwilds hosting on Linux, every distribution or graphics driver, a physical second device's firewall/trust configuration, or Windows service startup across a full OS reboot. The final Windows UI update-switch check remains unverified because desktop automation lost access. See [current testing details](https://github.com/stephenjarrett/Wyrmwatch/blob/sjarrett/initial-mvp/docs/testing.md).
