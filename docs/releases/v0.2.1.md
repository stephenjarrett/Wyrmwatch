# Wyrmwatch 0.2.1

Wyrmwatch's internal projects, namespaces, libraries, and Windows shutdown helper now consistently use the Wyrmwatch name. The shared Windows/Linux process adapters are in `Wyrmwatch.Platform`.

- Rename the core library, platform adapters, shutdown helper, and core tests, including their source folders and project references.
- Update builds, CI, and helper discovery. Package checks require the renamed libraries and reject leftover application files using the old names.
- Preserve existing workspace paths, server connections, process records, backup filenames, and the backup-format identifier so existing data remains compatible. Game-specific `RSDragonwilds` executable, configuration, and save-folder names remain unchanged.

## Downloads

- **Windows x64:** `Wyrmwatch-0.2.1-win-x64-setup.exe` — installs for the current user with a Start menu shortcut. The installer is currently unsigned.
- **Ubuntu/Debian x64:** `Wyrmwatch-0.2.1-linux-amd64.deb` — install with `sudo apt install ./Wyrmwatch-0.2.1-linux-amd64.deb`.
- **Portable:** `Wyrmwatch-win-x64.zip` and `Wyrmwatch-linux-x64.tar.gz`.

All packages include the .NET runtime, matching source, license notices, and accompanying SHA-256 files. Earlier release downloads retain the filenames they shipped with. See the [installation guide](https://github.com/stephenjarrett/Wyrmwatch/blob/v0.2.1/docs/installing.md).

This is an early release. The automated suite uses disposable fake servers; it does not certify actual Dragonwilds hosting on Linux. See the [testing details](https://github.com/stephenjarrett/Wyrmwatch/blob/v0.2.1/docs/testing.md) for coverage and deployment limits.
