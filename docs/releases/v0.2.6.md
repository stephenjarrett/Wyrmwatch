# Wyrmwatch 0.2.6

- Fix Windows server shutdown when Dragonwilds uses its graphical Server Console instead of a Windows text console. The manager requests the game's normal window-close shutdown, then waits for the server process to exit. Text-console servers continue to receive their normal shutdown signal.
- Keep shutdown conservative: validate the process identity and game-console window, refuse unexpected windows or access failures, and never force-kill a game server.
- Show actionable shutdown diagnostics and make stop/restart failure banners say the operation failed rather than implying the server stopped.

Regression tests use disposable graphical and text-console fixtures and verify graceful exit, preserved dummy world data and rejection of unrelated windows/processes. A background-manager smoke test now waits through expected busy responses before changing preferences.

Includes Windows and Linux packages, matching source, AGPL-3.0-only license notices and SHA-256 checksums. The bundled .NET runtime needs no separate installation. Existing servers, saves and backups are preserved. Linux remains a preview; graphical-console behavior on Windows services still needs real-game deployment validation.
