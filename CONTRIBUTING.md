# Contributing to Wyrmwatch

The canonical project is [stephenjarrett/Wyrmwatch](https://github.com/stephenjarrett/Wyrmwatch). Please open issues and propose improvements through pull requests here so the community can benefit from one maintained project.

Discuss substantial changes in an issue first. For fixes, open a focused pull request against the default branch, explain the user-visible change, and describe how you checked it. Maintainers review and decide which changes to accept.

Keep validation proportionate: use temporary game-data fixtures for backup/update safeguards and a short UI smoke check for interface changes. Never run tests against a real game installation. Preserve save files, existing configuration, and user-owned processes.

Anyone may open an issue or pull request. You do not need advance permission to fork, modify, test, or contribute. Redistribution is allowed under the [GNU AGPL version 3](LICENSE), including its source-sharing and notice requirements.

By intentionally submitting an original contribution for inclusion, you offer it under the project's `AGPL-3.0-only` license. Contributors retain their copyright; no copyright assignment or separate contributor agreement is required. Contribute only material you have the right to share, identify any separately licensed third-party material, and preserve its copyright and license notices.

Please send generally useful improvements here. Upstream pull requests are voluntary; the AGPL's source-sharing obligations do not require submitting changes to this repository. Review requests are routed to `@stephenjarrett` through CODEOWNERS; that file alone does not enforce branch protection.
