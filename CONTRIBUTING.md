# Contributing to Wyrmwatch

The canonical project is [stephenjarrett/Wyrmwatch](https://github.com/stephenjarrett/Wyrmwatch). Please open issues and propose improvements through pull requests here so the community can benefit from one maintained project.

Discuss substantial changes in an issue first. For fixes, open a focused pull request against the default branch, explain the user-visible change, and describe how you checked it. Maintainers review and decide which changes to accept.

Keep validation proportionate: use temporary game-data fixtures for backup/update safeguards and a short UI smoke check for interface changes. Never run tests against a real game installation. Preserve save files, existing configuration, and user-owned processes.

Anyone may open an issue or pull request. The [license](LICENSE) expressly permits contribution forks, modifications, and review/test artifacts. You do not need advance permission to contribute. Forks can retain their contribution history even if a pull request is closed without merging. Independent releases and redistribution outside the license's allowances require the project owner's written permission.

Contribute only material you have the right to share. Preserve third-party copyright and license notices. By submitting a contribution for inclusion, you accept the contribution grant in section 4 of the license: you keep your copyright and allow Stephen Jarrett to incorporate and distribute your contribution as part of Wyrmwatch under the project terms, including written redistribution permissions. This is not a copyright assignment.

Please send generally useful improvements here. Private modifications do not have to be submitted. Review requests are routed to `@stephenjarrett` through CODEOWNERS; that file alone does not enforce branch protection.
